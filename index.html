About this tool

Rotation is a rigid torsion of the back fragment about the selected bond; bond lengths and angles are idealised and not energy-minimised, so strain and energies are not modelled. Anti and gauche names are shown only when both reference groups are not hydrogen. Stereocentres in SMILES are not specified, so one arbitrary enantiomer is drawn.
